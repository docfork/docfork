The Libraries page gives you a unified view of every library indexed in your workspace — both private repositories you've connected and public libraries you've pinned from the Docfork catalogue.

Go to [app.docfork.com/libraries](https://app.docfork.com/libraries) to view your libraries.

## Private libraries

Private libraries are indexed from your own GitHub repositories. Each private library:

- Is scoped to your workspace — other workspaces can't access it
- Requires a [GitHub integration](/integrations/github) before you can add it
- Counts toward your plan's private library limit (visible on the [Usage](/core/usage) page)

### Adding a private library

1. Click **Add Library** on the Libraries page
2. Select a GitHub integration from the dropdown
3. Pick a repository from the repo picker — lists all repos accessible to your integration
4. Submit — Docfork queues an index job immediately

Once the job completes, the library is available for search across your workspace. Add it to a [Cabinet](/core/cabinets) to scope it to a specific project.

<Callout type="info">
  You can also type an `owner/repo` identifier directly if you know it, rather than browsing the
  picker.
</Callout>

### Re-indexing

Open a library's detail page and click **Re-index** to queue a new indexing run. Do this after pushing significant documentation updates to the repository.

Re-indexing an unchanged repository doesn't consume your monthly indexing budget — only changed content counts.

## Public libraries

Public libraries come from the Docfork catalogue (10,000+ open-source repositories). Adding a public library to your workspace pins it so it's consistently available in searches and can be added to [Cabinets](/core/cabinets).

To add a public library, click **Add Library** → search the public catalogue → select a result.

<Callout type="info">
  Public libraries are indexed and maintained by Docfork. No GitHub integration is needed.
</Callout>

## Library detail page

Click any library row to open its detail page. From here you can:

- **Edit metadata**: update the display name and description
- **Manage Cabinets**: add or remove the library from your workspace's Cabinets
- **Manage integrations**: link or unlink a GitHub integration (private libraries only)
- **View latest job**: jump to the most recent indexing job
- **Re-index**: trigger a new indexing run
- **Delete**: permanently remove the library from your workspace

## Library Access Scope

The **Library Access Scope** setting in [app.docfork.com/settings](https://app.docfork.com/settings) controls which libraries workspace API keys can search:

| Scope              | Behaviour                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Workspace Only** | API keys can only search libraries you've explicitly added to your workspace. Recommended for teams.         |
| **Public Index**   | API keys can search Docfork's full public catalogue, does **not** include libraries added to your workspace. |

Fine-grained per-API-key scope control is coming soon.
