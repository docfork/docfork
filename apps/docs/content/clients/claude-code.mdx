## Automatic Setup

The fastest way to set up Docfork in Claude Code:

```sh theme={null}
npx dgrep
```

This detects Claude Code, provisions an API key, and writes your `.mcp.json` config automatically.

---

## Plugin Marketplace

The Docfork plugin bundles MCP, skills, agents, and commands for documentation search. We're not in the official Anthropic marketplace yet—install from our GitHub marketplace:

```sh theme={null}
/plugin marketplace add docfork/docfork
/plugin install docfork@docfork
```

The plugin includes: `docfork:search_docs` and `docfork:fetch_doc` MCP tools, the `/docfork:docs` command, `docfork-docs` skill, and `docs-researcher` agent. See the [plugin README](https://github.com/docfork/docfork/tree/main/plugins/claude/docfork) for details.

## MCP-only installation

If you only need the MCP server without the plugin bundle, use one of the methods below. See [Claude Code MCP docs](https://docs.anthropic.com/en/docs/claude-code/mcp) for more info.

#### Remote Server Connection (recommended)

```sh theme={null}
claude mcp add --transport http docfork https://mcp.docfork.com/mcp --header "DOCFORK_API_KEY: YOUR_API_KEY"
```

#### Local Server Connection

```sh theme={null}
claude mcp add docfork -- npx -y docfork --api-key YOUR_API_KEY
```

#### Project-scoped (shared with team via `.mcp.json`)

```sh theme={null}
claude mcp add --transport http --scope project docfork https://mcp.docfork.com/mcp --header "DOCFORK_API_KEY: YOUR_API_KEY"
```

This creates a `.mcp.json` file at your project root that can be committed to git. Team members will be prompted to approve the server on first use.

#### Manual `.mcp.json` configuration

Add to your project's `.mcp.json`:

```json theme={null}
{
  "mcpServers": {
    "docfork": {
      "type": "http",
      "url": "https://mcp.docfork.com/mcp",
      "headers": {
        "DOCFORK_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
```

## Scopes

| Scope | Command | Where stored | Shared |
|---|---|---|---|
| Local (default) | `claude mcp add ...` | `~/.claude.json` | No |
| Project | `claude mcp add --scope project ...` | `.mcp.json` | Yes (git) |
| User | `claude mcp add --scope user ...` | `~/.claude.json` | No (all projects) |
